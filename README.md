# Zest

A D&D 5e character sheet. Variant Human Bard (College of Eloquence), Criminal background.
Wins by manipulating the ruleset and the terrain instead of out-statting anything.

- **[Open the sheet](https://bllindhandsrightfast29.github.io/zest/)** — phone reference. Trackers, dice roller, full spell text, trap playbook.
- **[Printable PDF](Zest-CharacterSheet.pdf)** — 2 pages, hand this to the DM.

`index.html` is a single self-contained file. All art is base64-embedded, fonts are system-only,
nothing is fetched at runtime. Save it and it works with no signal.

Rules text quoted from the SRD.
